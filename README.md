# FL Studio

![FL Studio](hero.jpg)

FL Studio is a complete digital audio workstation for Windows: composing, recording, editing, mixing and mastering in one program. Piano roll, playlist, mixer and a huge library of instruments and effects.

## Features

- Legendary piano roll for melodies and drums
- Full mixer with effects chains on every track
- VST plugin support, instruments and samples included
- Recording, audio editing and pitch correction
- Automation clips for any parameter
- Export to WAV, MP3, OGG and FLAC

## How to install

1. Download the archive from the link above.
2. Extract it with the password shown on this page (7-Zip or WinRAR).
3. Run FL Studio Setup.exe.
4. Follow the installer, then launch FL Studio from the desktop.

## System requirements

- Windows 10 or 11 (64-bit)
- 4 GB RAM, 4 GB free disk space
- Sound card with DirectSound drivers
